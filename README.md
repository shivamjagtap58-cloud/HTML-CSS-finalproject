# HTML-CSS-finalproject
# Amazon Home Page Clone 🛒

A front-end clone of the Amazon home page built using pure **HTML5** and **CSS3**. This project replicates the core user interface, navigation components, custom hero background, quad-box category grids, and interactive footer controls.

---

## ✨ Features Built

* **Navigation Bar:** Multi-section header featuring the Amazon logo, location selector, search bar with category dropdown, account options, and cart icon.
* **Hero Banner:** Full-width hero image with an integrated promotional message banner.
* **Product Grid Layout:** Responsive 4-column card container featuring custom multi-category sub-grids (`2x2` image panels).
* **Interactive Footer:** Complete multi-tier footer with "Back to Top" functionality, quick site links, and customized hover-activated language/currency dropdown selectors.

---

## 🛠️ Tech Stack & Concepts Applied

* **HTML5:** Semantic markup structure (`<header>`, `<nav>`, `<main>`, `<footer>`, `<ul>`, `<a>`).
* **CSS3:** 
  * Advanced Layouts: CSS Flexbox (`flex-wrap`, `justify-content`, `align-items`).
  * Positioning & Layering: Relative, absolute, and `z-index` layering with negative margins.
  * UI Interactivity: Custom hover effects, CSS pseudo-elements (`::after`), transition physics, and custom dropdown bridges.
  * Box Model: Precise padding, margins, borders, and `box-sizing: border-box`.
